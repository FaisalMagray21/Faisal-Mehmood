### 🔄 Waste Exchange & Resource Management System  
**Tech Stack:** Node.js · Express · MongoDB (Mongoose) · Socket.io · React.js · React Native  
A cross-platform (web + mobile) app for peer-to-peer resource and waste exchange, featuring:
- **Real-Time Chat & Notifications**  
- **Listings for Exchange** (tools, recyclables, surplus food, etc.)  
- **Product Exchange Functionality** with swap agreements  
- **Live Updates** via Socket.io  
- **Robust Data Handling** with well-defined Mongoose schemas (`User`, `Listing`, `Chat`, `Exchange`)
